# JAX WENO Solver

Исследовательский конечно-объёмный решатель скалярного и векторного уравнений
Бюргерса, реализованный с использованием JAX.

В проекте реализованы:

- конечно-объёмная реконструкция WENO девятого порядка;
- численный поток Русанова;
- периодические граничные условия, а также условия Дирихле, Неймана и свободного
  выхода;
- правые части скалярного и многомерного векторного уравнений Бюргерса;
- явные схемы Рунге—Кутты с адаптивным шагом по условию CFL;
- численные эксперименты и сценарии сравнения производительности CPU и GPU.

## Структура проекта

```text
boundary/       Граничные условия и заполнение фиктивных ячеек
operators/      Потоки, дивергенция, производные и оператор Лапласа
rhs/            Правые части скалярного и векторного уравнений Бюргерса
rk/             Явные схемы Рунге—Кутты
solver/         Интегрирование по времени и интерфейсы решателей
weno9/          Реконструкция WENO9
experiments/    Исследования сходимости, примеры и бенчмарки
```

## Текущее состояние

Численное ядро находится на этапе проверки и согласования. До использования
решателя в прикладных задачах необходимо унифицировать интерфейс интегрирования
по времени, согласовать схему Рунге—Кутты с ограничением устойчивости, точно
зафиксировать форму векторного уравнения и завершить тесты многомерной
сходимости.

## Системные требования

- Python 3.12 (текущая протестированная версия);
- JAX;
- NumPy;
- Matplotlib для запуска сценариев визуализации.

WSL не является обязательным для запуска проекта на CPU: JAX можно установить
непосредственно в Windows. Нативная Windows-версия JAX для CPU имеет
экспериментальный статус.

Для вычислений на NVIDIA GPU под Windows следует использовать WSL2. Нативный
CUDA-бэкенд JAX для Windows не поддерживается, а поддержка NVIDIA GPU через WSL2
пока имеет экспериментальный статус. Для разработки и первичных тестов на CPU
можно использовать как Windows, так и WSL2; для последующих GPU-бенчмарков в
этом проекте предполагается WSL2 или Linux.

Точные команды установки и запуска будут добавлены вместе с конфигурацией
пакета и зафиксированным списком зависимостей.
